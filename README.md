its implementation and package interface are not established. Do not
infer functionality from the repository name.

commands, or runtime tests. Repository CI checks line endings and GitHub Actions
security; scheduled OpenSSF Scorecard results become available after the workflow
runs on main. Windows-local prototypes and notes have not been
reviewed as part of this repository's documentation audit. No runtime behavior or
compatibility guarantees are documented here.
